Seasonal Picks

Picks movies from each user's watch history and the time of year. Playlists, the mirror folder and covers work on every client, including TV apps. The Suggested screen and home row are web only and need the File Transformation plugin.

Mirror library folder

Replaces a symlink script: the plugin fills a folder with symlinks to one user's picks. Point a Movies library at that folder and it shows on the TV home screen like any other library. Only symlinks in the folder are ever added or removed.

Deletes for real. Refused automatically if the folder is, contains, or is inside another library's folder, so it can't touch your Movies or TV folders.

Seasonal covers

Sets the cover of each Suggested playlist and the mirror library to match the season. Each season's cover is drawn from a design you can change with "Design cover" (decoration, title, background picture and more), or you can upload a finished image to use as it is.

Seasons

Keywords match whole words in the title or overview; tags match exactly. Both count as a strong match. Genres count as a weaker one. "Hide out of season" keeps strong matches out of picks for the rest of the year; a film that matches several seasons belongs to the one with the highest boost. Dates are MM-DD, or relative to Easter Sunday for Easter (e.g. easter-14 to easter+1).

Pick one to add it. Everything can be changed afterwards. Special days push their films forward on the day and never hide them the rest of the year; seasons can hide theirs.
